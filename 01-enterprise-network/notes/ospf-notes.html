1路由协议要解决的问题

包到了路由器，必须回答一个问题：从哪个口扔出去？

答案存在 路由表 里。小网络手写就行，但几百台设备、几千个网段时，手工维护会崩——任何一条链路断了，全网表格都得重写。

所以要让路由器 自己学会怎么走。这就是路由协议的全部意义。

一句话：路由协议不是让网络"通"的技术，而是让网络"断了能自己恢复"的技术。

2两种思路：打听 vs 看地图

所有路由协议只分两大流派，差别是"你怎么知道路"。

RIP（距离矢量）OSPF（链路状态）
怎么获取问邻居："去北京几跳？"每人一张完整地图，自己算
比喻路口问人：往前两个路口打开高德，自己规划
致命问题会绕圈（路由环路）不会绕圈
收敛速度分钟级秒级

RIP 为什么会绕圈？因为它是"听说"。A 说"去北京走 B"，B 说"走 A"，包就在两人之间来回弹到 TTL 耗尽。OSPF 因为有完整地图，算路时能看见"我要经过我自己"这种荒谬路径，直接排除。

3三张表：OSPF 的全部家当

一台路由器跑 OSPF，脑子里只装三样东西。

OSPF 的核心信仰：同一个区域里，所有路由器的 LSDB 必须完全一致。
所以看到 State = Full 之所以让人高兴，是因为 Full 的含义是"咱俩的地图已经对齐了"。

4LSA：地图是怎么拼出来的

LSDB 里的内容叫 LSA，一条 LSA 就是一张明信片。

（Link State Advertisement，链路状态通告）的内容是："我是谁，我旁边坐着谁"。

# LSW1 写的明信片
我是 LSW1（Router ID 1.1.1.1）
我连着：192.168.10.0/24、192.168.20.0/24、192.168.99.0/24
我的邻居：AR1（通过 10.0.0.0/30）

每台设备都写一张，互相传，最后每个人都集齐全班所有人的明信片——拼起来就是完整的座位表。这个过程叫 泛洪（Flooding）。

类型谁产生说什么比喻
Type-1每台路由器我是谁、连了哪些网段自我介绍
Type-2DR（班长）这个广播网段上有谁小组名单
Type-3ABR（区域边界）我这边有哪些网段别省概况
Type-5ASBR外面世界怎么走校门在哪
Type-5 是关键。它是唯一"外部路由"的载体，也是后面实战案例里出问题的地方。

5区域：为什么要把网络切开

一万台路由器每台存一万条 LSA，内存和 CPU 都扛不住。

区域内部传明细（Type-1/2），跨区域只传摘要（Type-3）
比喻：你在合肥要知道每条街，但不需要知道乌鲁木齐每条街——只需要知道"乌鲁木齐在西北，走高速能到"。
这样每台路由器的地图大小就可控了。

6邻居的七个状态（面试高频）

不用死背，理解"两个人从陌生到默契"的过程就行。

7DR / BDR：为什么要有班长

10 台路由器两两建邻居需要 45 条关系，LSA 泛洪会变成广播风暴。

比喻：收作业不需要每个人互相交换，都交给班长，班长汇总完再发给大家。
选举规则
优先级高者胜（默认 1）→ 优先级相同比 Router ID，大的赢
所以
配 router-id 1.1.1.1 不只是起个名字，它还参与选举

8Cost：路有多贵

有了地图，就像高德算最短路。OSPF 用 Cost 衡量"这条路多贵"。

Cost = 参考带宽 / 接口带宽 = 100Mbps / 带宽
接口Cost
千兆（1000M）1
百兆（100M）1（最小值就是 1）
十兆（10M）10
2M 专线48

一条路径的总 Cost = 沿途所有接口 Cost 之和，取最小的。你在 display ospf lsdb ase 里看到的 Metric: 1 就是这个。

9内部路由 vs 外部路由

全篇最重要的一节，实战案例的坑就在这里。

内部路由外部路由
类型Type-1/2/3Type-5
谁产生域内任何路由器只有 ASBR
内容我这个网段在哪外面世界怎么走
例子192.168.10.0/240.0.0.0/0 默认路由

ASBR（自治系统边界路由器）= 同时连着 OSPF 域和外部网络的设备。

核心比喻：
一个班 40 个学生，每个人都知道班里同学的座位（内部路由）。
但校门在哪，只有班主任知道（外部路由）。

如果有个同学举手说"校门在东边"，但他自己从来没出过校门——这不是帮忙，是误导。
只有 AR1 有资格宣告"去外网怎么走"

10实战复盘：默认路由的四个回合

把上面的知识串起来，重放一次真实排障过程。

  1. 第一回合：为什么 PC1 通不了 PC5 PC1 的包到 LSW1，LSW1 查路由表只有 192.168.x 直连，没有 0.0.0.0/0，直接丢弃。
    根因：LSW1 不知道"去外网交给谁"。
  2. 第二回合：为什么必须在 AR1 上配 需要让 AR1 主动宣告"想去校外交给我"。这在 OSPF 里等于 AR1 产生一条 Type-5 LSA，内容为 Ls id: 0.0.0.0。
    你后来查到的就是这张明信片： 
    Type      : External     # 外部路由
Ls id     : 0.0.0.0      # 默认路由
Adv rtr   : 2.2.2.2      # AR1 在发布
Metric    : 1
  3. 第三回合：为什么必须加 always default-route-advertise 默认要求本机路由表里已有默认路由才发布。但 AR1 去 200.1.1.2 是直连的，压根不需要默认路由——所以它一条 LSA 都不产生。
    加 always = "不管我有没有，强制发布"。
  4. 第四回合：为什么在 LSW1 上配会把事情搞坏 在 LSW1 上配 = 让没出过校门的学生举手说"校门在东边"。后果： 
    AR1 路由表： 0.0.0.0/0 → 10.0.0.1（LSW1）   # 错误！
LSW1 路由表：0.0.0.0/0 → 10.0.0.2（AR1）
    去外网的包变成 AR1 发给 LSW1，LSW1 发回 AR1，像两只手互相传球，永远送不出去。
    撤销后假路标消失，只剩 AR1 的真路标，网络立刻通。
一句话记住：默认路由是"最后一道出口"的宣告，只能由真正有出口的设备发布。
位置错了，不是"不生效"，而是主动制造环路。
